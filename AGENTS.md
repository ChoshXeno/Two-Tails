# Two Tails project instructions

- Read [Docs/PROJECT_STATUS.md](Docs/PROJECT_STATUS.md) at the beginning of each work session.
- When requirements or project decisions are needed, read the [Notion Agent Operating Guide](https://app.notion.com/p/4120be84637f8140aa04c1aea2b376a7) first, then the [Two Tails Project Roadmap](https://app.notion.com/p/4120be84637f81958a18f28aabcaf369). Use `instructions_version: "0.0.6"` when the Notion tool supports it.
- Keep code and repository documentation in this repository. Save project decisions and development journals according to the Notion Operating Guide.
- Use English for all player-visible text, including HUD prompts, buttons, status and error messages, pause menus, and on-screen prototype debug text.
- Determine implementation status from the actual code, Unity assets, installed packages, and test results. Record the evidence and its scope.
- Distinguish **reported complete by the user** (user handover), **implemented** (confirmed in project files), **verified** (confirmed by an observed check or test), and **awaiting testing on a physical device** (hardware validation pending). Apply each label only to the work it describes.
- Update [Docs/PROJECT_STATUS.md](Docs/PROJECT_STATUS.md) at the end of each task with the current status, evidence, and next step.
- Do not upgrade Unity, expand the task scope, or overwrite existing user changes without authorization.
